## 🌐 Landing Page

This project is my implementation of the Landing Page project in **The Odin Project** curriculum. It serves as a practical foundation for mastering modern web layouts, CSS style and Flexbox positioning from scratch.

### 🛠️ Project Overview
The primary goal of this project was to take a raw visual design spec and translate it into awell-structured webpage using semantic HTML and CSS. The result is a landing page complete with a hero header, feature showcase cards, a highlighted quote section, and a call-to-action banner.

### ✨ Key Learnings & Skills Demonstrated
- 📐 **CSS Flexbox Layouts:** Mastering alignment, direction, wrapping, and distribution (`justify-content`, `align-items`, `flex-direction`) to build fluid page sections
- 🏗️ **Semantic Page Architecture:** Structuring content logically using `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` tags
- 🎨 **Visual Styling & CSS Variables:** Implementing custom color palettes, background contrast, clean typography scales, and border radiuses
- 🖼️ **Media & Card Component Design:** Flexibly aligning image assets alongside text content and creating uniform feature cards
- 💡 **Design Specification Execution:** Translating visual design mockups directly into CSS styling

### 🛠️ Built With
- **Technologies:** HTML5, CSS
- **Version Control:** Git, GitHub
- **Code Editor:** Visual Studio Code
